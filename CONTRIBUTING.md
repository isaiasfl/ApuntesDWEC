# Contribuir a estos apuntes

Este repositorio contiene material docente de Isaías Fernández Lozano (Isaías FL).

Las contribuciones son bienvenidas si mejoran la claridad, corrigen errores o añaden ejercicios útiles para el alumnado.

## Antes de proponer cambios

- Mantén siempre la autoría original del material.
- Usa ejemplos sencillos, comentados y orientados a clase.
- Evita añadir dependencias innecesarias.
- Si actualizas documentación técnica, enlaza fuentes oficiales.
- Si cambias un ejercicio, intenta mantener el nivel progresivo.

## Tipos de aportación

- Corrección de erratas.
- Mejora de ejemplos.
- Nuevos ejercicios.
- Actualización de enlaces o documentación.
- Propuestas de proyectos puente hacia React o Angular.

## Estilo

- Usa Markdown claro.
- Prefiere títulos descriptivos.
- Incluye comentarios en ejemplos cuando ayuden a entender la intención.
- No mezcles demasiados conceptos nuevos en un único ejercicio.
